# YouTube Analytics Frontend

Next.js frontend for the YouTube Analytics system.

## Setup

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Features

- Dashboard with channel overview
- Channel detail pages
- Video analytics
- Trending videos
- Alert management
- Channel comparison

## Technology

- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- React Query for data fetching
- Recharts for data visualization
